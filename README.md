# Amzaon-Clone
🛒 Amazon Clone (Frontend Only)
This project is a static clone of the Amazon homepage built using only HTML and CSS. It's designed for learning and showcasing frontend development skills, focusing on layout design, responsive structure, and styling techniques.


🚀 Features
Fully responsive layout
Amazon-like navbar and search bar
Product grid and category sections
Footer with links and info sections
Clean and consistent design


🛠️ Technologies Used
HTML5 – For creating the structure and content

CSS3 – For styling and layout using Flexbox and Grid

📂 Folder Structure
amazon-clone/
│
├── index.html      # Main HTML structure
└── style.css       # Styling file


📌 Notes
This is a static project — no JavaScript functionality (like search, cart, or login) is implemented.
Images and icons may be sourced from Amazon or placeholder assets for demo purposes only.
This project is intended for educational use only and is not affiliated with Amazon.


💡 What You’ll Learn
Structuring complex web layouts with HTML
Styling and layout with Flexbox & Grid
Responsive design practices
Cloning popular UIs for skill development
